《NZ-STATION 隐私政策》

生效日期：2026-10-01 · 站长：南浊

一、我们收集什么

  • 城市级位置（默认）：所有访客进入本站时，通过 IP 地址解析「城市/国家」级别的粗略位置，用于站点访问统计。不签到、不授权，你的访问仅记录到城市粒度。
  • GPS 精确位置（自愿签到）：仅当你主动点击「定位签到并进入」并通过浏览器授权后，本站才会获取你的 GPS 坐标（经纬度），并可能通过高德地图 API 将坐标转换为省市区文字。浏览器会先弹出系统级授权框，你拒绝授权则本站拿不到任何精确位置。
  • 技术信息：访问时间、浏览器标识（User-Agent）、来源页。

二、数据用来做什么

  • 站长了解本站被谁访问、来自哪里（访客足迹记录）。
  • 不做任何自动化决策、 profiling 或对外共享。

三、数据存在哪、谁能看

  • 存储于站长自有的服务器（仅站长后台可见）。
  • 记录条目包含：时间、城市（或签到时的坐标/省市）、来源方式、浏览器标识。不收集姓名、手机号、账号等身份信息。

四、你的权利

  • 拒绝授权不影响浏览：点「直接进入（不签到）」即可，仅记录城市级统计。
  • 如需删除你的访问记录，联系站长即可（凭时间+城市定位删除）。

五、第三方服务

  • GitHub API（公共仓库数据展示）、高德地图 API（签到坐标转文字，仅在你主动签到时调用）、ipwho.is（IP 城市解析）。
